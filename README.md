\# boyia language



\## Description

```

Boyia language is a rust only OOP program language engine, which is chinese owner for language contribution.

中国人自己开发的OOP编程语言引擎，基于纯Rust，自定义语法规则，可作为脚本引擎替代Python做编程开发。

```



\## Features

1. 支持原生扩展，可用Rust编写内置类(Builtins)，也可编写Native函数作为扩展支持。
2. 支持面向对象开发，支持class定义，继承等OOP基础语法。
3. 支持异步开发模式，Cli中已加入https，file，zip等原生异步接口
